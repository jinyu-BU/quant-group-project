# 量化交易大作业：双均线择时策略

## 项目简介
本项目基于 A 股沪深300指数（sh000300），构建了经典的双均线（5日/20日）择时策略。项目包含数据获取、信号生成、回测引擎与结果可视化四大模块，并进行了样本内（2015-2020）与样本外（2021-2024）的对比分析，最终输出了四大核心回测指标与净值对比图。

## 环境安装
在终端运行以下命令安装所需依赖：
pip install -r requirements.txt

## 运行方式
在项目根目录下执行：
python main.py

## 数据源
akshare，沪深300指数（sh000300）

## 模块说明
1. `data_loader.py`：数据获取与本地保存
2. `strategy.py`：双均线金叉/死叉信号生成
3. `backtest.py`：包含 T+1 执行机制的回测引擎与指标计算
4. `plot_result.py`：净值曲线可视化
